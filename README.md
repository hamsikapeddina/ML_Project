# Heart Disease Prediction Using Regularized Logistic Regression

## Live Website

**Try the deployed application:** https://hamsikapeddina.github.io/ML_Project/

## About the Project

This project demonstrates heart disease prediction using three trained machine-learning models:

- Logistic Regression
- Ridge Logistic Regression
- Lasso Logistic Regression

The frontend is built with React and Vite and is hosted on GitHub Pages. The Python FastAPI backend is hosted on Render and loads the trained model pipelines to return predictions.

## How to Use

1. Open the [live website](https://hamsikapeddina.github.io/ML_Project/).
2. Navigate to the heart disease prediction page.
3. Enter the requested health-related feature values.
4. Select a model and click **Predict** to view its output.
